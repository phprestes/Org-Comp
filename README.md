## Requisitos

- Um simulador RISC-V que execute `.asm` (por exemplo, o **RARS**)

## Como Executar

Abra o arquivo `.asm` desejado no simulador, monte e execute.

## Estrutura do Projeto

- `/Aulas`: exemplos das aulas, em ordem: `a1_helloworld`, `a2_helloplus`, `a3_fatorial`, `a4_strcpy`, `a5_strcpy_dinamico`.
- `/Exercicios`: `e1_bubble_sort`, `e2_soma`, `e3_str_inverte` (e versão dinâmica), `e4_strcat` (e versão com função), `e5_strcpy`, `strcmp`.
- `/Atividades`: `fatorialfunc.asm` e `trabalho.asm`.

## Funcionalidades Implementadas

- **Impressão e leitura** de texto no console.
- **Fatorial**, com e sem função.
- **Operações com strings**: cópia (`strcpy`, também dinâmica), concatenação (`strcat`), comparação (`strcmp`) e inversão.
- **Ordenação** por Bubble Sort.
